# Smart Event Booking Portal

This is a simple web application where users can view events, book tickets, cancel bookings, and see booking statistics.

## 🔧 Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 Features

- View list of events
- Book seats for events
- Cancel bookings
- Search events by name
- Filter events by category
- Show only available events
- Dashboard showing:
  - Total events
  - Total bookings
  - Seats booked
  - Top event
  - Revenue

## ⚙️ How It Works

- Events are created using a class in JavaScript
- Booking is handled using simple objects
- Data is loaded using async/await (simulated fetch)
- DOM is updated dynamically when booking or canceling

## 🧠 Concepts Used

- Classes and Objects
- Prototype methods
- Promises and Async/Await
- DOM Manipulation
- Array methods (filter, loop)
- Event handling
- Error handling
